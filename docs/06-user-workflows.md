# Knowledge Dynamics — User Workflows

## 1. Reader Flow
```
Visit Homepage → Browse Journals → Select Journal → Browse Archive
  → Select Issue → Select Article → Read Abstract
  → Download PDF / Cite / Share
  → Explore Author Profile → View Related Articles
```

## 2. Registration & Profile Flow
```
Register (name, email, password) → Verify Email → Login
  → Complete Profile (institution, country, research interests)
  → Create Researcher Profile → Public at /{username}
```

## 3. Author Submission Flow
```
Login → Submit Research → Select Journal
  → Step 1: Journal Selection
  → Step 2: Article Metadata (title, abstract, type, keywords)
  → Step 3: Authors & Affiliations
  → Step 4: File Upload (manuscript PDF, supplementary)
  → Step 5: Declarations (ethics, COI, funding)
  → Step 6: Review Summary
  → Step 7: Submit → Confirmation
```

## 4. Author Dashboard Flow
```
Login → Dashboard → View Submissions
  → Draft (continue editing)
  → Submitted (waiting for screening)
  → Under Review (waiting for reviewers)
  → Revision Required → Upload Revision → Resubmit
  → Accepted → View Published Article
  → Rejected → View Decision
```

## 5. Editor Workflow
```
Login → Editor Dashboard → New Submissions Queue
  → Screen Manuscript (desk reject or proceed)
  → Assign to Section Editor (optional)
  → Invite Reviewers → Track Review Progress
  → Read Reviews → Make Decision
    → Accept → Move to Production
    → Minor Revision → Notify Author
    → Major Revision → Notify Author
    → Reject → Notify Author with Comments
  → Production → Assign Copyeditor → Assign Layout Editor
  → Publish → Assign to Issue → Set Published Date
```

## 6. Reviewer Workflow
```
Receive Invitation Email → Login → View Assignment
  → Accept or Decline Invitation
  → If Accept: Read Manuscript → Submit Review
    → Recommendation (accept/minor/major/reject)
    → Comments to Author (non-confidential)
    → Comments to Editor (confidential)
    → Quality Score
  → Submit Review → Done
```

## 7. Admin Workflow
```
Login → Admin Dashboard → Overview Metrics
  → Manage Users (create, edit, assign roles)
  → Manage Journals (create, configure, settings, policies)
  → Manage Articles (edit metadata, publish, retract)
  → Manage Services (KD Proofreading, consulting)
  → Manage Pages (about, contact, custom)
  → Manage Settings (company info, contact, social)
  → View Audit Logs (track all changes)
  → URL Mappings (legacy redirects)
```

## 8. Service Request Flow (KD Proofreading)
```
Visit Services → Select Proofreading → Submit Request
  → Provide Document + Requirements
  → Admin Assigns to Proofreader
  → Proofreader Completes Work
  → Quality Check → Deliver to Client
```
